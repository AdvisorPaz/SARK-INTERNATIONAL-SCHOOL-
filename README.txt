SARK INTERNATIONAL SCHOOL WEBSITE
==================================

FILES
- index.html           Main website page
- styles.css           Theme, layout, mobile responsiveness, animations
- script.js            Scroll reveals, active side navigation, music control
- assets/school-logo.jpg  Logo image supplied by the user
- assets/design-reference.png  Generated design reference (not used as a page background)

HOW TO PUBLISH ON GITHUB PAGES
1. Make a backup of your current repository first.
2. Upload index.html, styles.css, script.js and the assets folder to the ROOT of your existing repository.
3. Keep the folder structure exactly as shown. Do not upload only the files inside assets without the folder.
4. Commit the changes, wait a minute, then refresh your published Pages link.

IMPORTANT
- This website uses a stylised CSS illustration of a school building because a verified campus photograph was not included with the files available for this package. Replace it with an approved real school photo when ready.
- Gallery tiles are decorative placeholders, not actual school photos. Replace them with real school photos before public launch.
- Leadership cards currently use initials rather than portraits. Add approved photos only with permission.
- Student achievements are intentionally presented as a verification prompt. Add names, event names and placements only after confirming them against original certificates and with school management.
- Confirm school details, facilities, contact details and timings with school management before treating the page as official.
- The optional music button is included, but music is not bundled. To enable it, add a properly licensed audio file named assets/soft-ambient.mp3. The site will not autoplay audio; visitors must press the button.
- External Google Fonts are used for typography. If unavailable, fallback fonts will display.
- The design is responsive and includes reduced-motion support.

BACKUP RECOMMENDATION
Before replacing your live files, download or duplicate your existing index.html and any assets so you can restore the previous version if needed.

THE SARK INTERNATIONAL SCHOOL & HOSTEL — WEBSITE PACKAGE

FILES
- index.html: main school website
- alliance.html: separate Alliance website-services page
- styles.css: responsive styling
- script.js: intro animation, local visitor notes, enquiry mailto and local FAQ assistant
- assets/: images extracted from the supplied school-information PDF and the Alliance logo image supplied in chat

HOW TO PREVIEW
1. Extract the ZIP folder.
2. Open index.html in a browser. For the best results, upload the entire folder to a static web host or GitHub repository; keep the assets folder beside the HTML files.
3. alliance.html is linked from the bottom Alliance banner.

IMPORTANT LIMITATIONS / CHECKS BEFORE PUBLIC RELEASE
- The enquiry form opens the visitor's email app. It does not send in the background and requires the visitor to send the email.
- Visitor notes are saved in the visitor's own browser only. They are not a shared review system and are not moderated centrally.
- The “I” assistant is a local FAQ based on information shown on this page, not a connected AI service.
- The music player intentionally does not autoplay. Add a licensed soft piano/ambient MP3 file to assets (for example assets/soft-ambient.mp3) and update the <source src=""> in index.html to assets/soft-ambient.mp3 to enable it.
- Verify school details, official CBSE wording, current facilities, winter closing time, principal name spelling and achievement evidence with school management before publishing.
- Obtain permission for student photographs before making the website public.
- This is a static website. Shared reviews, real AI responses, secure email processing, admin login and databases require a backend or third-party service.
- Google Fonts are loaded from the internet; the site uses fallback fonts if unavailable.
